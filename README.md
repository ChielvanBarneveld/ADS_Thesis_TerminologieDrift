# ADS Thesis — Terminology drift in PTSD literature

Master's thesis Applied Data Science, Utrecht University. Reproducibility bundle for the experiments described in `THESIS.docx` / `THESIS.md` (kept separately in the author's working folder, not in this repo).

## Research question

> *Can a Graph Neural Network on the citation network beat the standard ELAS u4 TF-IDF baseline at recovering PTSD literature published under historical terminology (shell shock, soldier's heart, war neurosis, battle fatigue, combat stress reaction)?*

Three sub-questions, each implemented as a separate experiment under `code/`:

| SQ  | Question                                                              | Code         | Status       |
| --- | --------------------------------------------------------------------- | ------------ | ------------ |
| SQ1 | Sentinel injection: how visible is drift to ELAS u4?                  | `code/SQ1/`  | active       |
| SQ2 | Regex drift sweep: WSS@95 + loss heatmaps over (intensity × era)      | `code/SQ2/`  | active       |
| SQ3 | GNN on the FORAS citation network vs. ELAS u4                         | `code/SQ3/`  | scaffold     |

## Reproducibility contract

> Cloning this repo and running the scripts under `code/` must regenerate every file under `outputs/` exactly as referenced in the thesis.

- **Code** — committed.
- **Input data** — committed (FORAS xlsx, OpenAlex candidate-pool snapshot, hand-curated sentinels + rewrites, term-frequency JSON).
- **Outputs** — *not* committed. Empty `outputs/{SQ1,SQ2,SQ3}/` directories are kept as `.gitkeep` placeholders. Every file under `outputs/` is regenerated by re-running the relevant `code/SQx/` script.
- **One regenerable data file** — `data/SQ2/foras_regex_rewritten.parquet` (~30 MB). Skipped because `code/SQ2/build_regex_dataset.py` deterministically rebuilds it in ~30 seconds from the committed FORAS xlsx + term distribution.

## How to run

```bash
git clone https://github.com/ChielvanBarneveld/ADS_Thesis_TerminologieDrift.git
cd ADS_Thesis_TerminologieDrift

# 1. Python env
python -m venv .venv
.venv\Scripts\activate           # Windows PowerShell
# source .venv/bin/activate      # macOS/Linux
pip install -r requirements.txt  # (added in a later commit)

# 2. SQ1 — sentinel injection (40 ELAS u4 simulations)
python code/SQ1/build_csvs_from_xlsx.py
python code/SQ1/run_simulations_cli.py
python code/SQ1/make_summary_cli.py

# 3. SQ2 — regex drift sweep (180 simulations)
python code/SQ2/build_regex_dataset.py
python code/SQ2/run_simulations_grid.py
python code/SQ2/make_heatmaps.py

# 4. SQ3 — GNN  (scaffold only at this point)
```

Each `code/SQx/` folder has its own `README.md` that documents inputs, outputs and the order of scripts.

## Citing the data

The FORAS-update corpus is from van de Schoot et al. (2025). The OpenAlex candidate-pool snapshot was queried on 28 April 2026 using 29 historical PTSD terms (English, German, French); see `data/SQ1/README.md` for the exact query list.
