# `data/SQ1/` — Candidate pool, sentinels, and rewrites

| File                       | Origin                                                     |
| -------------------------- | ---------------------------------------------------------- |
| `candidates_with_terms.csv`| Output of `code/SQ1/build_candidate_pool.py`. OpenAlex term-search across 29 historical PTSD terms (English, German, French), in two pools — pre-1980 (term in title or abstract) and post-1980 (term in title only). 28 April 2026 snapshot. Committed because the OpenAlex API is non-deterministic; re-running the script later may yield a slightly different pool. |
| `raw/`                     | Per `(term, pool)` raw OpenAlex responses as JSONL. **Not committed** (~MBs, regenerable). `build_candidate_pool.py` writes these as a side-effect and can resume from cache via `--skip-existing`. |
| `sentinels.json`           | v3 sentinel set (3 papers, cohort-diverse): Solomon 1988 (HIGH bucket), Kardiner 1947 (MEDIAN), Grinker 1944 (LOW). Hand-curated from `sentinels_shortlist.csv`. |
| `sentinels_shortlist.csv`  | Working shortlist used during the sentinel-selection step (LOW/MEDIAN/HIGH stratification by reverse-citation density). |
| `rewrites.json`            | Three rewrite-conditions × three sentinels = 9 versions. Conditions: `raw` (verbatim OpenAlex abstract), `period` (PTSD tokens replaced with historical equivalents + minimal period-appropriate edits), `full` (complete rewrite satisfying all FORAS criteria with modern jargon). Generated by `code/SQ1/generate_rewrites.py` (LLM-assisted; frozen after manual review). |
| `rewrites_data.json`       | Companion file with metadata about each rewrite (LLM model, prompt version, manual-review notes). |

## Schema of `candidates_with_terms.csv`

| Column                              | Meaning                                                          |
| ----------------------------------- | ---------------------------------------------------------------- |
| `openalex_id`                       | Bare W-id (e.g. `W2057711239`)                                   |
| `doi`, `title`, `year`, `language`, `type`, `abstract` | OpenAlex metadata                              |
| `pools`                             | `pre1980` / `post1980_title` / both (semicolon-separated)        |
| `found_via_terms`                   | Historical terms that matched this paper (semicolon-separated)   |
| `n_terms`                           | Number of distinct terms                                         |
| `in_foras`                          | True iff this OpenAlex id is also in the FORAS xlsx              |
| `foras_label_FT`, `foras_label_TIAB`| FORAS inclusion labels (only set if `in_foras`)                  |
| `referenced_works`                  | Semicolon-separated W-ids of papers this candidate cites         |
| `n_referenced`                      | Length of `referenced_works`                                     |
| `n_edges_to_foras_FT_included`      | How many of the candidate's references are FORAS-FT-positive     |
| `n_edges_to_foras_TIAB_included`    | Same for FORAS-TIAB-positive                                     |

## Used by

- `code/SQ1/select_sentinels.py` — reads the pool, stratifies LOW/MEDIAN/HIGH buckets by reverse-citation density.
- `code/SQ1/filter_v3_sentinels.py` — freezes the v3 sentinel set (cohort-diversity check).
- `code/SQ1/generate_rewrites.py` — produces `rewrites.json` from sentinels.
- `code/SQ1/run_simulations.py` — reads sentinels + rewrites and runs the 40 ELAS u4 simulations.
- `code/SQ2/build_regex_dataset.py` — reads `found_via_terms` to derive `term_distribution.json`.

## Re-generating

```bash
python code/SQ1/build_candidate_pool.py
```

This runs ~80 OpenAlex queries (29 terms × 2 pools, plus cursor pagination). The full fetch took ~12 minutes on 28 April 2026 over a residential connection. The committed snapshot is the canonical one for this thesis; re-running may produce a slightly different pool because OpenAlex is continuously updated.
